### Опис проєкту

Web-система для відстеження доставки одягу в реальному часі, орієнтована на малі та середні інтернет-магазини. Дозволяє клієнтам, менеджерам і кур’єрам працювати в єдиному інтерфейсі без використання сторонніх сервісів.

**Ключові можливості:**
- Відстеження статусу замовлення в реальному часі
- Показ геолокації кур’єра на карті
- Автоматичні push-сповіщення в Telegram
- Рольова модель доступу (Клієнт / Менеджер / Кур’єр)
- Повністю працює всередині месенджера Telegram

---

### 🛠 Технологічний стек

| Частина       | Технології                          |
|---------------|-------------------------------------|
| **Frontend**  | Telegram Web App + React 18 + Vite |
| **Backend**   | FastAPI (Python 3.11) + Pydantic   |
| **База даних**| Supabase (PostgreSQL + Realtime)   |
| **Авторизація**| Telegram ID + Supabase Auth       |
| **Карта**     | Leaflet + OpenStreetMap            |
